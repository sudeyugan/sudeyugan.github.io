# 苏的鱼干 · 个人主页

本地静态 HTML、CSS 和原生 JavaScript。双击 `index.html` 打开，无需安装依赖、构建或启动服务。素材和视频均在本地，可离线运行。

## 修改文字

在 IDE 中编辑 **`assets/content.js`**，保存后刷新主页。昵称、介绍、角色对白和能力说明集中在这个文件中；“认识一下”的 QQ、Steam、问题及签文在 `assets/connection-data.js` 中维护。本人偏好通过 `tools/answers.html` 点选，保存到 `assets/owner-answers.js`。换行使用 `\n`，`index.html` 主要负责页面结构。

网页内的文字编辑入口、编辑页面及文件导出流程已移除。

## 浏览与互动

- 滚轮／触控滚动推动横向场景，目录与底部细线导航可直接跳转，支持前进后退和 URL hash。
- 鱼指针可以连续转圈；游动与点击共用局部水面模拟，带有水色暗部和亮缘，停止后淡出。游动按距离与时间间隔采样，避免波纹过密。背景保持静止。
- 首页是一张可互动的排版海报：四个字分别回应拨动、按压、牵引和整圈旋转；可拖拽并弹回，也能用键盘 Enter／空格触发，方向键轻推。小字逐字回应，名字下的线可拨动，招呼气泡可点击，矢量星号切换首页局部配色与形状。「关于我」「认识一下」是首页的两个入口；作品信息只在小鱼页展示。关于我以连续画廊展示音乐、小说、轻小说、网文、动漫、电影与游戏，点击收藏图像可打开短评，Escape 关闭；认识一下提供求签与合拍度测试，QQ、Steam 始终可直接使用；求签经过按住摇签、松手出签、展开纸签，测试结果以整体同频动效和数值呈现。
- 鱼靠近卡片时，最近的一段边缘轻轻弯曲；掠过链接时，下方细线会回弹。所有反馈局限在操作附近。
- 小鱼提供 **WebM 形象**与**桌面小鱼**。WebM 的每段素材沿用一隅保存的缩放、位移参数，集中在 `assets/xiaoyu/placements.js` 中。桌面形态沿用一隅原版的鼠标眼神：页面内移动时双眼跟随，停留会注视，久置后缓慢回正；拖动、睡觉与减弱动效时暂停。

| 对小鱼的操作 | 触发的 WebM 动画 |
| --- | --- |
| 点头发 | 理理头发 |
| 点身体 | 害羞一下 |
| 按住约 0.72 秒再松开 | 伸个懒腰 |
| 在角色区域左右挥动鼠标 | 招手 |
| 拖动后放下 | 庆祝新位置 |

操作提示也可以直接点击。聚焦角色后，Enter／空格触发头部回应，Shift + Enter／空格触发身体回应，方向键移动位置。动作库另有倾听、思考等选择，Escape 关闭。桌面形态使用已有 PNG 姿态回应。

“陪你聊聊／日常协助／有边界的 AI”是预设的本地能力片段，不连接真实模型或私人记录。

手机上较长的场景可在场景内继续滚动。页脚可减弱动效，并尊重系统偏好；触屏不会显示额外的鱼指针或指针波纹。

## 关于我与本地音乐

页面名称仍为「关于我」。收藏改为一段连续画廊：音乐、哈利·波特、备胎女友、间客、魔笛 MAGI、情书、星际拓荒。所有内容都在原生滚动流中，每幅与画廊可视区等高并铺满；向下浏览时连续衔接，停止时使用原生 proximity 吸附辅助完整停留；没有分类切换按钮，不拦截滚轮或触摸板事件，也不按一次手势强制翻页。触屏可直接上下浏览，键盘聚焦画廊后可用 PageDown／PageUp、Home／End。到达首尾后，继续滚动可衔接整站场景。上方仅保留当前阅读位置与背景音乐控制。图片可点击展开短评，Escape 关闭。

这六项是用户指定的收藏，短评是可继续修改的初稿。修改 `assets/content.js` 的 `favorites` 数组可替换名称、短评、图片与 `fullTitle`。备胎女友按《我当备胎女友也没关系。》呈现；哈利·波特以三册原作封面组成书架；轻小说使用原作两卷封面；《间客》使用起点正式封面；Magi 使用官方海报和标志；《情书》使用发行方剧照；《星际拓荒》使用官方商店截图。图片与来源在 `assets/collection/` 及该目录的 `sources.json`。六幅另有局部交互：来信拆封、夹书签、接通信号、鲁赫漂浮、借阅卡盖章和追踪信号。这些是本页的视觉道具，不改变原作素材。装饰动效仅在画面可见时运行，减弱动效时停用。
背景音乐使用本地《Move Mountains a cappella Scene》。从首页或章节导航点击进入时，利用这次点击准备播放，在「关于我」出现时淡入；滚动进入或直接打开时也会尝试播放，浏览器拒绝有声自动播放时显示「开启配乐」。标题旁的彩色声音形体可点击暂停／继续。浏览收藏不中断音乐；离开本面淡出暂停，回来继续；主动暂停会保持暂停，切到后台也会暂停。

声音形体跟随这首歌实际测得的六组频段包络，数据预存在 `assets/music/spectrum.js`，以音频 `currentTime` 插值读取，再以弹性缓动改变形态；不是随机跳动，也不依赖 `file://` 下可能受限制的 Web Audio。播放时所有频道都可见，暂停后回到静态造型。替换歌曲时须重新生成对应频段数据。

画廊第一张的音乐画面使用本地 LRC 的 17 句时间点。关键词由 Canvas 字形采样为细密粒子，切句时在旧字形与新字形间重组；六频段包络驱动细微起伏，副歌出现透视山形网格。鼠标经过会推开局部粒子，离开回弹；轻点形成一圈局部扩散。完整句子仍以 DOM 文本保留，歌词可读性与屏幕阅读器不依赖 Canvas。暂停后停止音频驱动的动画，主动碰触文字仍可产生短暂反馈。音乐画面离开可视区域时停止绘制；减弱动效显示完整实色文字，并保留所有播放控制。

切入音乐画面时接续当前歌曲进度；暂停定格、拖动定位。进度条支持左右键快进／后退五秒、Home／End 定位，歌词下方另有上一句／下一句按钮；支持音量和单曲循环。试听副本、歌词数据与原 LRC 在 `assets/music/`，原音频未修改。在 `assets/music/lyrics.js` 修改 `start`／`end` 可微调句级同步，`focus` 指定本句的粒子关键词，`layout` 决定文字姿态。时间依据原文件 `assets/music/move-mountains.lrc`，粒子形变并非逐字演唱时间。

## “认识一下”：一签与合拍度

直接打开 `index.html#contact`。先展示合拍度测试，后是抽签入口；QQ 可复制，Steam 打开已提供的个人主页；旧题库编辑工具已移除。

- **抽一支签**：木质签筒采用独立的透视场景绘制，包含空心筒口、木纹、铜边与逐支竹签。按住产生带阻尼的摇动，松手经过停摇、抬签、揭晓；也可轻点／按 Enter 求签。停摇抬签后，三折纸笺从中间向两侧展开，诗句显墨、印章落定；手机上将解签一折向下打开。纸张分别保留折痕、明暗和阴影，签诗与解签分栏呈现。十二支签各有签等、签诗、解签与宜缓事项；同一次页面访问中，连续两次不重复同一支签。离开场景取消正在进行的摇签与出签，已揭晓的签会保留。减弱动效直接揭晓。
- **看看合拍度**：62 道问题，首轮十五题，可追加十题至二十五题。鼠标、触屏或数字键选择后，短暂确认即自动进入下一题；重复点击不会连跳，切换入口或离页取消尚未执行的跳题，上一题仍可修改。小说、网文、游戏、动漫是前置问题，只有选择“很喜欢／比较喜欢”才会抽取其细分题；“2077”重复题已合并。其余问题涵盖故事、Rap、自我描述、相处方式及观念。四道前置题穿插在第 1、4、7、10 题；首轮最多两道细分兴趣题，至少九道故事、自我、相处与观念题，按主题平衡抽取。新增情境涉及信任建立、争执修复、付出是否对等、秘密边界、道歉之后以及如何面对人的改变，选项代表不同处理方式。
- **改变前面的回答**：后续已抽题及回答会清除，按新的条件继续抽取，避免留下已经关闭的分支。相同回答则保留原有进度。
- **分级计分**：原有 42 题依据选项的连续位置或语义坐标比较距离；新增 20 道情境题为每对选项设置对称的相近分值，相同选项为满分，不同选项也有部分分。先按主题计算加权平均，再平均各个有结果的主题，避免某类细分题数量过多而主导分数。前置题权重减半；“没接触过”及跳过不计入。全跳过显示“—”。这是一套可调的趣味比较方式。
- **答题体验**：题干居中排版，短选项横向展开，长选项和手机使用自适应布局；选择后文字收束、细小光点流向进度，再自动进入下一题。进度点可直接返回已出现的题目，数字键 1—4 仍可作答。过程中的视觉反馈只表示选择已收到，不透露任何单题是否契合。
- **只表达整体合拍度**：结果为两束绿、金光点围绕总分运动，轨迹带有透视、细丝、微粒与局部会合光晕。总分控制两组相位运动的耦合强度与速度差；分数高时更容易同步，低时保持更独立的节奏。轻拨施加有上限的短暂推力，先平滑加速、逐渐错开，再由耦合恢复；不会直接改变光点位置，连续点击也不会瞬移或失控。趋于同步时，两条尾迹逐渐汇成一束，并以共同节奏明暗呼吸；较低合拍度保留独立尾迹。可暂停或保存 PNG。不展示单题契合度、双方选项、逐题图表或文字总结；视觉层只接收总分、题数、待本人补答题数及预览状态。
- **动效生命周期**：运动限于本页，约 30 帧每秒；切换到抽签、离开场景或进入后台即暂停绘制，减弱动效时使用静态轨迹。全跳过时显示“—”及中性光点，不暗示一个虚构的合拍度。

### 点选本人答案

双击 **`tools/answers.html`**，按阅读、游戏、动漫、故事、音乐、相处方式等主题填写，也可以只查看未填题。每次选择自动保留此浏览器的草稿；填到后面可用底部的保存条，不必回到顶部。

1. 点击“保存到答案文件”，在支持文件写入的浏览器中选择主页的 **`assets/owner-answers.js`** 并保存。
2. 也可点击“下载答案文件”，用下载的同名文件替换 **`assets/owner-answers.js`**。
3. 刷新主页即可使用已填写的真实偏好；把这个答案文件一同提交到 GitHub。设置页重新打开时会读取它，也可导入以前导出的 JS／JSON 答案继续修改。

草稿不会直接影响主页或来访者的计分，必须保存／替换答案文件后才生效。外部更新过答案文件时优先载入文件，并提供旧草稿恢复，避免悄悄覆盖新版。原有 42 个本人答案已保留。新增 20 题需在“尚未填写”中补答；未填写的新增题不使用预览偏好、不参与计分，结果仅提示待补答题数。旧题若缺少本人答案仍使用明确标注的预览值。`1.txt` 保留为原来的题目清单，无需再用文本作答。设置页是独立的本地工具，主站没有编辑入口；它不提供新增题目或编辑作品功能。

所有交互在本地 HTML 中运行，不上传、不保存访客答案；两个入口之间切换保留当前进度。离页暂停画面，刷新重新开始；减少动态效果的系统设置和页脚动效开关都生效。

## Git 与静态托管

保留本地 Git 历史，目前没有远程仓库，没有自动推送或发布配置。将本目录提交到你指定的 GitHub 仓库即可管理。资源采用相对路径，支持 GitHub Pages 项目子路径。`.nojekyll` 跳过 Jekyll 处理；`outputs/` 中的录屏、截图、备份不纳入版本管理。

可选的 HTTP 预览方式：

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

然后打开 `http://localhost:8080`。直接打开 HTML 同样可用。
